# A collection of smart clothing for Titan

Стратегия и инвестиционный пакет умной одежды «Титан» — продолжения экосистемы «Здоровье Титана» (репозиторий [`mrfreshval-web/health-of-a-titan`](https://github.com/mrfreshval-web/health-of-a-titan), приложение MATUTA). Одежда сама поддерживает комфорт тела и передаёт данные в MATUTA.

Три линейки: **Smart Casual** (верхняя одежда, обувь, аксессуары, от −25 до +15 °C), **Sport** (кроссфит и функциональный тренинг: влага, пульс, цвет по пульсовой зоне, температура, напряжение мышц), **Function** (экстрим, лыжи и сноуборд, расширенный диапазон).

## Правила

- Язык документов — русский, формат — Markdown.
- Каждый отдел пишет только в свои папки; сдача — через пулл-реквест.
- Любая цифра или утверждение — со ссылкой на источник. Метки: `[Факт: S#]` — есть источник из реестра; `[Оценка]` — наш расчёт, ход расчёта показан; `[Гипотеза]` — требует проверки, указано как. Уверенность: **В** / **С** / **Н**.
- Реестр источников Стратегии — [01-research/sources.md](01-research/sources.md). Другие отделы ведут свой реестр в своей папке или ссылаются прямо на URL.
- Опора — исследования и технологии 2025–2026 годов; более старые данные помечаются годом.
