# 07. Итоговая матрица: функция → научная обоснованность → ценность для Титана → приоритет

Совместный документ отдела «Наука и медицина». Обоснования и источники — в документах [01](01-sensing-from-textile.md)–[06](06-medical-device-boundary.md).

## Легенда

- **Обоснованность** — уровень доказательности, что функция физиологически осмысленна и даёт пользу: A сильная, B умеренная, C слабая, Г гипотеза (см. [README](README.md)).
- **Надёжность из ткани** — насколько точно функцию можно реализовать именно в одежде: высокая / средняя / низкая.
- **Ценность для Титана** — оценка отдела (Г): польза для пользователя + отличие от конкурентов + вклад в экосистему MATUTA.
- **Регуляторный риск** — низкий (wellness), средний (пограничная формулировка), высокий (медизделие).
- **Приоритет:** **P0** — MVP; **P1** — вторая волна; **P2** — исследование и пилот; **✘** — не делаем.

> Итоговый порядок запуска линеек по проекту определяется данными о спросе. Матрица задаёт научный приоритет внутри каждой линейки.

## 2. Состав MVP по линейкам (научная рекомендация)

**Smart Casual (P0):** зональный подогрев торса и кистей с автоматикой по микроклимату и коже; автоматическое снижение подогрева при входе в тепло; аппаратная защита от ожогов; температура и влажность микроклимата; интеграция с MATUTA (погода, профиль, физиология из других устройств). Биометрию из пальто не обещаем.

**Sport (P0):** ЭКГ-пульс в компрессионном топе; цветовая индикация зоны с гистерезисом и приватным режимом; температура кожи; оценка потерь влаги с калибровкой; подсчёт повторений; спортивная компрессия.

**Function (P0):** зональный подогрев с режимом «подъёмник» и аварийным режимом; предупреждения о риске обморожения; защита от ожогов; базовый слой с ЭКГ-пульсом — во второй волне.

## 3. Замечания для «адвоката дьявола»

Отдел сам выделяет слабые места, чтобы критика была предметной:

1. **Цветовая индикация пульса** — ценность во многом маркетинговая; атлет не видит свою спину. Проверить на фокус-группах кроссфитеров, нужна ли функция, и какая технология цвета выдержит стирку и пот.
2. **Оценка потерь влаги** зависит от дисциплины пользователя (взвешивание). Без калибровки ошибка может быть ±30–50 % (Г, исходя из межиндивидуального разброса [Baker2017]).
3. **ЭМГ в кроссфите** не валидирована именно для кроссфита; потребуется собственное исследование.
4. **Ценность подогрева в городе** при −5…+5 °C (основная часть сезона в большинстве городов) может быть ниже, чем кажется: важнее вентиляция и отвод влаги (Г).
5. **Батарея на морозе** — главный технологический риск Function: заявленное время работы должно проверяться при −20 °C, а не при +20 °C.
